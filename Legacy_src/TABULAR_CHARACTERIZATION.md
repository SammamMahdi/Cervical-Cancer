## 1. The dataset at a glance

- **858 patients**, 36 columns → **26 leakage-safe features** after dropping the four `Dx:*` prior-diagnosis
  columns and the two ~92%-missing `STDs: Time since …` columns.
- **Four binary targets** (diagnostic tests), all severely imbalanced:

| Target | Positives | Rate | Imbalance |
|---|---|---|---|
| Hinselmann | 35 | 4.1% | 23:1 |
| Schiller | 74 | 8.6% | 10:1 |
| Citology | 44 | 5.1% | 18:1 |
| **Biopsy** (primary) | **55** | **6.4%** | **14.6:1** |
| any-of-4 | 102 | 11.9% | 7.4:1 |

→ **Fig 02** (prevalence), **Fig 03** (target co-occurrence: Schiller↔Biopsy φ≈0.6; Citology is the outlier),
**Fig 01** (missingness: the STD block is ~12% missing together, IUD/hormonal ~13–14%).

## 2. Why the accuracy is capped at AUROC ≈ 0.65 (it is the *data*, not the model)

Three independent views say the same thing: **the risk factors barely separate the classes.**

- **Univariate signal is near-zero (Fig 05).** The single most predictive feature for Biopsy is
  *Num of pregnancies* at **AUROC 0.572**; every other feature is 0.52–0.57, and **mutual information is
  < 0.01** for all of them.
- **The classes overlap completely (Fig 07 PCA, Fig 08 t-SNE).** Biopsy-positive patients sit *inside*
  the negative cloud — there is no region a model could carve out. **Fig 09** shows the top-6 features'
  distributions are nearly identical across classes.
- **Variance is diffuse (Fig 06).** No small set of principal components captures the data; there is no
  low-dimensional structure aligned with the target.

> **Bottom line.** A model can only recover signal that exists. With max univariate AUROC 0.57 and
> MI < 0.01, **no estimator will honestly exceed ~0.66** on Biopsy. This is a property of the
> questionnaire, not a modelling failure.

## 3. The leakage traps — how the literature "reaches" 0.98–1.00 (Fig 10)

The published 0.98–1.00 AUC on this dataset is reproducible **only** by cheating. Measured here:

| Setup | AUROC | Verdict |
|---|---|---|
| **A. Honest** (leakage-safe features, proper out-of-fold CV) | **0.650** | the real number |
| **B. Oversample *before* the split** (duplicate/SMOTE the whole set, then split) | **0.994** | fake — test copies leak into train |
| **C. Predict `Dx:Cancer` from its sibling `Dx` columns** (RandomForest) | **0.998** | fake — copying the answer |

**Do not** do B or C. Never oversample before splitting (keep SMOTE/class-weights *inside* the training
fold); never keep the `Dx:*` columns; never report accuracy (at 6.4% prevalence, predicting "always
negative" already scores 93.6%).

## 4. Model bake-off (leakage-safe, repeated 5-fold OOF AUROC + bootstrap 95% CI) — Fig 11

Target = Biopsy; median-imputed; class-weighted / `scale_pos_weight`; 3 seeds × 5-fold.

| Model | AUROC | ±SD | 95% CI |
|---|---|---|---|
| **kNN** (k=21, distance) | **0.657** | 0.012 | [0.580, 0.743] |
| **RandomForest** | 0.655 | 0.007 | [0.577, 0.746] |
| HistGradientBoosting | 0.634 | 0.015 | [0.564, 0.724] |
| ExtraTrees | 0.607 | 0.014 | [0.535, 0.710] |
| XGBoost | 0.607 | 0.018 | [0.546, 0.707] |
| SVM-RBF | 0.588 | 0.022 | [0.498, 0.674] |
| GaussianNB | 0.583 | 0.024 | [0.457, 0.642] |
| MLP | 0.570 | 0.031 | [0.493, 0.670] |
| LogReg (L2) | 0.521 | 0.042 | [0.443, 0.631] |

**Read this honestly:** every family lands in **0.52–0.66 with heavily overlapping CIs**. kNN and
RandomForest are nominally top, but with **55 positives the CI half-width is ~0.08**, so
**differences below ~0.05 AUROC are not resolvable** — kNN's 0.002 edge over RandomForest is noise.
Linear models (LogReg) do worst → the little signal there is, is non-linear.

## 5. Recommended models for this dataset

Given the profile — **small (n=858), severely imbalanced (~6%), mixed binary+continuous, missing values,
weak non-linear signal** — the suitable families, in order:

1. **Gradient-boosted decision trees — the default.** HistGradientBoosting (ingests NaN natively → no
   imputation-leakage), or XGBoost / LightGBM / CatBoost with `scale_pos_weight`. Best-in-class for small
   tabular data. *Recommended deployable choice: HistGradientBoosting for robustness (native NaN, stable
   calibration), even though kNN nominally tops the bake-off within noise.*
2. **Bagged trees — RandomForest / ExtraTrees.** Competitive here (RF 0.655), robust, class-weight support.
3. **TabPFN** *(not installed — `pip install tabpfn`)*. A transformer **foundation model for tables with
   n < 10k**, frequently best out-of-the-box on tiny datasets and needs no tuning. **The single most
   promising untried lever** — worth adding as a candidate.
4. **kNN (scaled, distance-weighted).** Nominally best (0.657) but fragile (needs scaling + imputation, no
   native NaN, sensitive to k); prefer trees for deployment.
5. **Regularized Logistic Regression.** Keep only as an interpretable baseline — weakest here (0.521).

**Mandatory wrappers regardless of model:**
- **Probability calibration** — `CalibratedClassifierCV` (sigmoid/isotonic); already in
  [`src/tabular.py`](src/tabular.py). Fusion needs a *calibrated* `P_tab`, not just a ranking.
- **Imbalance via class weights / `scale_pos_weight`**, never oversample-before-split.
- **Report PR-AUC, sensitivity@fixed-specificity, ECE — not accuracy.**

## 6. Legitimate ways to (marginally) improve — and honest expected gains

| Lever | Expected gain | Note |
|---|---|---|
| Install & try **TabPFN / LightGBM / CatBoost** | +0.00 → +0.02 | most promising; still bounded by §2 |
| **Stacking** the top-3 (RF + HGB + kNN) + calibrated meta-learner | ≈ +0.01 | within noise |
| **Threshold tuning** for the operating point | 0 on AUROC | raises *sensitivity* at fixed specificity — useful clinically |
| **`any-of-4`** composite target | not higher (≈0.61) | more positives → more *stable* CI, not more signal |
| Missingness-indicator features / interactions | ≈ 0 | tested earlier — no measurable help |

There is **no honest path past ~0.66** for Biopsy from these questionnaire features. The realistic goal is
not higher AUROC but a **well-calibrated, imbalance-aware, honestly-reported** weak triage signal — which
is exactly the role the fusion design assigns to the tabular expert (raise suspicion, never overrule the
image; see [`IDEAL_PIPELINE.md`](IDEAL_PIPELINE.md) §5).
