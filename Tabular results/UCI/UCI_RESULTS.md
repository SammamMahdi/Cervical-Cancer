# Tabular Results — UCI Cervical Cancer (Risk Factors)

Execution of the tabular work plan ([`legacy_src/TABULAR_PLAN.md`](../legacy_src/TABULAR_PLAN.md)).
All figures in `figures/` (PDF + PNG @600 dpi); all numbers in `metrics/tabular_plan_results.json`.
Generated by [`legacy_src/src/tabular_plan.py`](../legacy_src/src/tabular_plan.py) +
[`tabular_characterize.py`](../legacy_src/src/tabular_characterize.py). Leakage-safe throughout
(`Dx:*` dropped, no oversample-before-split, SMOTE only inside train folds). Primary target = **Biopsy**
(55 positives, 6.4%).

---

## Headline

**Every legitimate lever — 12 model families incl. a foundation model, feature engineering, target choice,
calibration — lands the honest AUROC at ≈ 0.65–0.66.** The ceiling is imposed by the data (max univariate
AUROC 0.57, mutual information < 0.01 per feature), not by the model. The real, reportable wins are
**(i) a small but genuine +0.027 from interaction features** and **(ii) near-perfect calibration
(ECE 0.042 → 0.007)**, which matters more than the third decimal of AUROC for a screening tool.

|---|---|---|---|
| **kNN** (k=21, distance) | **0.657** | [0.580, 0.743] | nominal best (within noise of RF) |
| RandomForest | 0.655 | [0.577, 0.746] | robust; recommended deployable |
| HistGradientBoosting | 0.634 | [0.564, 0.724] | native-NaN, stable |
| Stacking (RF+LGBM+kNN) | 0.628 | [0.540, 0.708] | no lift over its members |
| LightGBM | 0.619 | [0.564, 0.722] | |
| **TabPFN v2** (cloud) | **0.613** | [0.530, 0.694] | **foundation model — does *not* break the ceiling** |
| ExtraTrees / XGBoost | 0.607 | — | |
| CatBoost | 0.600 | [0.522, 0.689] | |
| SVM-RBF / GaussianNB / MLP | 0.57–0.59 | — | |

**Read this honestly:** with 55 positives the CI half-width is ~0.08, so **differences below ~0.05 AUROC are
noise**. TabPFN (0.613) is mid-pack — exactly as predicted: a model pre-trained on millions of synthetic
tables still cannot recover signal that is not in the features.

## Track B — feature engineering *(the one lever that added signal)*

Figure: `B_feature_engineering`. Workhorse = LightGBM.

| Feature set | AUROC | 95% CI |
|---|---|---|
| baseline (26) | 0.630 | [0.564, 0.722] |
| **+ interactions (29)** | **0.655** | [0.604, 0.747] |
| + aggregates (29) | 0.640 | [0.593, 0.738] |
| **+ all engineered (32)** | **0.657** | [0.602, 0.751] |
| + select top-12 (MI) | 0.603 | [0.557, 0.706] |

The interaction/ratio features — **partners-per-year-since-first-intercourse, pack-years, pregnancies-per-age**
— add a real **+0.027** (still within CI, but consistent and directionally clear). Aggressive feature
selection *hurts* (throws away weak-but-additive signal).

## Track C — target strategy

Figure: `C_target_strategy`.

| Target | Positives | AUROC | 95% CI |
|---|---|---|---|
| **Biopsy** | 55 | **0.630** | [0.564, 0.722] |
| any-of-4 | 102 | 0.615 | [0.561, 0.677] (tightest CI) |
| Schiller | 74 | 0.549 | [0.475, 0.628] |
| Citology | 44 | 0.523 | ≤ chance |
| Hinselmann | 35 | 0.472 | ≤ chance |

**Biopsy is the right primary target.** `any-of-4` gives the tightest CI (most positives) but not higher
AUROC. Citology and Hinselmann are at or below chance — exclude them.

## Track D — imbalance & calibration *(the "clinically better" win)*

Figures: `D_reliability`, `D_operating_point`.

| Setup | AUROC | ECE |
|---|---|---|
| class-weight (uncalibrated) | 0.647 | 0.042 |
| SMOTE inside folds | 0.639 | 0.046 |
| **class-weight + isotonic** | **0.650** | **0.007** |

- **Isotonic calibration cuts ECE from 0.042 to 0.007** with no AUROC loss — the model's probabilities become
  trustworthy, which is exactly what the fusion needs from `P_tab`.
- **SMOTE-inside-folds does not beat class weights** — so no oversampling is warranted.
- **Operating point** for a high-sensitivity screen: at **sensitivity 0.80**, specificity is **0.34**
  (PR-AUC 0.170). This is the honest cost of a weak triage signal — it flags most true positives but also
  many false positives.

## Track F — interpretability

Figure: `F_permutation_importance` (LightGBM) + `12_shap_summary` (XGBoost SHAP, from the characterization).
The top movers are the engineered exposure features + Age + STD counts — consistent with the univariate
analysis. No single feature dominates, confirming the diffuse, weak signal.

---

## Conclusion (pre-registered stop rule met)

The plan's stop rule was: *if Tracks A–C do not push OOF AUROC above 0.70 (upper CI), finalise the
questionnaire as a weak triage signal by nature.* **Best achieved: ≈ 0.657** (kNN, or engineered LightGBM),
well under 0.70. **We therefore finalise the tabular arm as a calibrated weak triage** — its role in the
fusion (raise suspicion, never overrule the image; [`IDEAL_PIPELINE.md`](../legacy_src/IDEAL_PIPELINE.md) §5).

**What genuinely improved things:** (1) interaction features (+0.027 AUROC), (2) isotonic calibration
(ECE 0.042 → 0.007). **What did not:** foundation models (TabPFN 0.613), oversampling, stacking, aggressive
feature selection. The honest ceiling stands at ~0.66, and no legitimate method exceeds it.
